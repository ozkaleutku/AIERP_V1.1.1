# 🏠 Ana Sayfa Kullanım Kılavuzu

**Dosya:** `Home.jsx`
**Erişim:** `/`

1.  **Genel Bakış**
    *   Sistemin başlangıç noktasıdır.
    *   Kullanıcıyı karşılar ve ana modüllere hızlı erişim sağlar.

2.  **Özellikler**
    *   **Kritik Uyarılar:** Stok seviyesi kritik olan ürünler veya geciken siparişler burada özet geçilir.
    *   **Navigasyon:** Sol menüye alternatif olarak sık kullanılan ekranlara (Ürünler, Siparişler) butonlarla yönlendirme yapar.

3.  **Kullanım İpuçları**
    *   Güne başlarken bu ekrandaki uyarıları kontrol edin.
    *   Eğer "Sistem Bağlantı Hatası" alıyorsanız, Backend servisinin (`python main.py`) çalıştığından emin olun.
